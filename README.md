# physengine — учебный физический движок на C++

Курсовой проект: движок для численного моделирования физических явлений
(механика → МКТ/термодинамика → физика ядра), написанный с нуля на C++20
без сторонних физических и графических библиотек.

## Цели проекта

- Чистое ядро (`libphys`), не зависящее от графики и ввода.
- Сменные численные интеграторы: явный/симплектический Эйлер, Верле, RK4.
- Каждый моделируемый эффект снабжён численной проверкой против аналитики.
- Два бэкенда рендера за одним интерфейсом: headless (PNG/MP4) и оконный (SFML).
- Юнит-тесты на doctest, сборка одним Makefile.

## Структура репозитория

```
physengine/
├── include/phys/     # публичные заголовки ядра (math, world, forces, integrator)
├── src/              # реализация ядра и headless-рендера
├── tests/            # юнит-тесты (doctest)
├── scenes/           # физические сцены-пресеты (YAML-подобные .scene)
├── examples/         # готовые примеры запуска
├── tools/            # вспомогательные скрипты (кадры → MP4, графики)
├── third_party/      # header-only зависимости (doctest, stb_image_write)
└── docs/             # DESIGN.md и изображения к нему
```

## Сборка и запуск

Требуется: `g++ >= 13` (C++20), `make`, для видео — `ffmpeg`.

```bash
make            # сборка ядра, CLI и тестов
make test       # юнит-тесты (аналитика + рендер)
make demo       # демо «двойная звезда»: PNG-кадры + CSV в output/
make demo_video # то же + видео MP4 (60 к/с, h264)
```

Каждое моделирование в проекте визуализируется: кадры со следами
траекторий, видео MP4, графики из CSV — см. раздел «Визуализация»
в [docs/DESIGN.md](docs/DESIGN.md).
